# Software architecture baseline

**Style:** Modular Monolith + Hexagonal Architecture + durable event-driven orchestration.

```text
PySide6 UI (future)   CLI (future)   Web/API (optional)
          \              |              /
             Application Commands/Queries
                         |
                 Workflow Orchestrator
            (DAG, state machine, resource policy)
                 /                 \
        MP3 artwork branch    MP4 karaoke branch
        Mutagen/APIC          lyrics -> align -> review -> ASS -> FFmpeg
                 \                 /
               QC, output manifest, delivery
                         |
             SQLite operational SSOT + outbox
                 Filesystem artifacts + hashes
```

## Layer boundaries
- `domain`: deterministic models and rules; imports neither Qt nor external providers.
- `application`: use cases, commands, queries and orchestration coordination.
- `ports`: typed interfaces to assets, metadata, aligners, renderer, persistence and event sink.
- `adapters`: Mutagen, FFmpeg, provider-specific AI, SQLite, PySide6 bridge.
- `paths`: sole resolver for application roots, bundles, data and workspace roots.

## Ownership and SSOT
- SQLite is authoritative for job, step, revision, approvals, checkpoint, artifact metadata and outbox events.
- Immutable external source assets and generated bytes remain authoritative on filesystem, with hashes and root-relative locators stored by engine.
- Git is authoritative for source, schemas, templates, tests and ADRs.
- UI stores ephemeral view state only. State transitions occur through commands and optimistic revision checks.

## Lifecycle
Batch -> Job -> Step. Each step uses `PENDING/RUNNING/SUCCEEDED/FAILED/BLOCKED/RETRY_WAIT/CANCELLED/SKIPPED`; jobs allow `PARTIAL_SUCCESS`. Two branches are independently tracked. Publishing artifacts follows stage -> validate -> same-filesystem atomic rename -> reconcile with DB. Never overwrite source.

## Event consistency
Record state change + event outbox within one SQLite transaction. Dispatcher delivers at-least-once; consumers are idempotent by event_id and sequence. Reconnecting UI fetches a fresh SSOT snapshot (replay only as optimization); progress events are not authoritative.

## Worker execution
CPU-heavy media work must run in subprocesses, not Qt UI thread or asyncio event loop. On Windows 8 GB RAM start with one video render and one heavyweight AI worker **not simultaneously until measurements justify it**. Steps are restartable using input hashes and configuration/revision cache keys.

## Path and locale
Central PathManager supports development/frozen, bundled resources, portable.flag, AppData fallback, external root rebinding and path validation. For program-generated numbers enforce explicit ASCII 0–9 formatting and test under different Windows locales.

## Risk decisions
- Sung Thai forced alignment is a research and validation problem, not a proven accuracy guarantee.
- UI preview and final text rendering must share measurement and render rules; unsupported effects must fail validation rather than silently degrade.
- Presets are versioned immutable built-ins, layered with user/job overrides and checked for backend capability.
